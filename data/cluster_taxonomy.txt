# Cluster Taxonomy Knowledge Base

This document defines the official maintenance cluster taxonomy.
Each cluster has a cluster ID, parent group, and short description.

Use this taxonomy as the authoritative mapping for questions like:
- What is cluster 38?
- What parent group does c_38 belong to?
- Which clusters are flight-control related?
- Which clusters are baffle child clusters?
- What does c_22 represent?
