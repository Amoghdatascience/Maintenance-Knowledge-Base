# Cluster c_37: rocker cover loose/leak/damage

Cluster c_37 is used for maintenance records related to rocker cover loose/leak/damage.
The cluster should be assigned only when the problem description and corrective action provide enough evidence.

## Inclusion Signals

- rocker cover leak
- valve cover loose
- oil seep near rocker cover
- rocker gasket damaged
- cover screw loose
- cover cracked

## Corrective Actions

- tightened rocker cover
- replaced rocker cover gasket
- resealed valve cover
- cleaned oil residue
- performed leak check
- replaced damaged cover

## Exclusion Rules

Exclude records that mention only a generic inspection with no corrective action.
Exclude records where the key component token is missing.
Exclude unrelated records that contain a similar word but describe a different component.
