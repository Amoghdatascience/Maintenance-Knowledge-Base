# Cluster c_28: intake gasket leak/damage

Cluster c_28 is used for maintenance records related to intake gasket leak/damage.
The cluster should be assigned only when the problem description and corrective action provide enough evidence.

## Inclusion Signals

- intake gasket leak
- induction leak
- rough running due to intake leak
- intake manifold gasket
- air leak near intake
- intake flange seep

## Corrective Actions

- removed and replaced intake gasket
- resealed intake
- torqued intake flange
- performed leak check
- installed new gasket
- verified roughness corrected

## Exclusion Rules

Exclude records that mention only a generic inspection with no corrective action.
Exclude records where the key component token is missing.
Exclude unrelated records that contain a similar word but describe a different component.
