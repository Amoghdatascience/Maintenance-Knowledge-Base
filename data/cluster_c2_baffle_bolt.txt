# Cluster c_2: baffle bolt issue

Cluster c_2 is used for maintenance records related to baffle bolt issue.
The cluster should be assigned only when the problem description and corrective action provide enough evidence.

## Inclusion Signals

- baffle bolt missing
- baffle bolt loose
- damaged baffle bolt
- bolt securing baffle
- baffle attach bolt
- baffle hardware bolt

## Corrective Actions

- installed new baffle bolt
- tightened baffle bolt
- replaced damaged bolt
- secured baffle with correct bolt
- torqued baffle hardware

## Exclusion Rules

Exclude records that mention only a generic inspection with no corrective action.
Exclude records where the key component token is missing.
For baffle child clusters, both the parent token 'baffle' and the child token must appear in the problem/action text.
Exclude unrelated records that contain a similar word but describe a different component.
